# Lingua Forge Academy PRO

A standalone professional English **and Italian** teaching workspace. Open `index.html` with Live Server (or any static server). No build step is required.

## English (EN)
Original, level-aligned curriculum: Kids Pre-A1–B2, Teens A1–B2, Adults A1–C2 — coursebooks, Grammar in Use (contents pages + numbered units, Murphy-style order), Vocabulary in Use (Oxford-style picture units), IELTS-style Reading Studio (paragraphs A–D with True/False/Not Given, Summary completion, Multiple choice), listening, speaking, writing, flashcards, workbooks, assessments, teacher tools, students, homework, planner (60/90-minute lesson programmes), games and progress.

## Italiano (IT)
A full Italian section built like the classic series (Nuovo Espresso, Progetto Italiano, Grammatica in Uso):

- **Corsi sfogliabili (flip books)** — three coursebook series (A1–C2, 36 lessons) rendered as real flip books with a spine, turning pages, cover and clickable contents; each lesson has Lessico (illustrated), Grammatica (spiegazione + esercizi), Lettura (IELTS-style), Ascolto (TTS), Parlare and Scrivere.
- **Grammatica in Uso** — 17 grammar topics, 41 level entries (A1–C2): rule in one line + extended explanation + checkable exercises, available as an interactive flip grammar book per level.
- **Lessico in Uso** — 180 illustrated words (30 per level A1–C2) with picture, IPA and category, in 6 flip vocabulary books.
- **Lettura** — 8 authentic IELTS-style readings with Vero/Falso/Non indicato, summary completion and multiple choice, with Italian text-to-speech.
- **Risorse** — researched real resources: coursebooks (Nuovissimo Progetto Italiano, Nuovo Espresso, Chiaro!, Via del Corso, Al dente, Nuova grammatica pratica, Grammatica avanzata), YouTube channels (Learn Italian with Lucrezia, Italy Made Easy, Italiano Automatico, LearnAmo, Podcast Italiano) and websites (One World Italiano, Rai Scuola, Alma, Edilingua, Loescher, WordReference/Treccani).

Visuals use lightweight emoji/graphic illustrations and CSS so the app works offline without an image library.
