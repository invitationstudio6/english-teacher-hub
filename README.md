# Lingua Forge Academy PRO

A standalone professional English teaching workspace. This folder is intentionally named differently from previous English Teacher Hub versions.

Open `index.html` with Live Server. No build step is required.

The curriculum is original and level-aligned. It includes Kids Pre-A1–B2, Teens A1–B2, Adults A1–C2, coursebook/unit/lesson navigation, vocabulary, grammar, reading, listening, speaking, writing, flashcards, workbook, assessment, teacher tools, students, homework, planner, games and progress.

Visuals use lightweight emoji/graphic illustrations and CSS so the app works offline without an image library.
